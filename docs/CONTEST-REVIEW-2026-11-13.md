## 참가와 일정

- 대한민국 국민, 개인 또는 4명 이하 팀. 같은 사람의 복수 참가작 중복 신청 불가. 팀의 실제 인원·국적·중복 여부는 별도 확인한다. (약관 제3조)
- 작동하는 서비스의 정확한 호스트명(서브도메인 포함)과 서비스 설명을 적고 미작성 서류를 작성·서명해 신청 폼에 제출한다. 주최자가 서비스 도메인을 확인하고 등록 완료를 회신한다. 최초 집계는 등록 완료일부터다. (신청 안내·약관 제4조)
- 등록 마감 2026-12-03, 산정 종료 12-13. 전체 재원 소진 시 조기 마감 가능. 대시보드 업데이트는 매일 오후 2시. 등록 마감의 시각은 확인하지 못했다.
- 일반 일정의 측정은 12-14~18에 12-13까지의 수치를 조회해 확정, 12-21 통지, 이의는 12-24까지, 지급은 공고상 12-28 예정. 조기 종료 시 별도 정산 절차가 적용된다. (약관 제4·5조, 공고)
- 메인 화면의 11-01부터라는 전체 산정 기간과 참가자별 등록 완료일부터라는 조건은 함께 읽는다. 테스트 또는 제출만으로 등록 완료라고 볼 수 없다.

## 집계, 상금, 권리

- 순 사용자는 등록 호스트를 경유한 활성 사용자를 산정 기간 전체에서 중복 제거한 수다. 같은 사용자의 반복 방문은 해당 참가자에게 1명이며 같은 사용자가 서로 다른 참가자를 거치면 각 참가자별로 산정한다. 페이지뷰·클릭 수와 다르다. 일정 체류나 페이지 이동 등 분석 도구의 참여 요건이 있으나 정확한 수치는 공개되지 않았다. (약관 제2조)
- 이용자 브라우저를 거치지 않는 서버 호출, 추적 파라미터 추가·단축 링크·중간 페이지, 경유 과정에서 유입 경로가 유실되는 인앱 브라우저나 리다이렉트, 등록 호스트 불일치, 참여 요건 미충족은 집계가 빠질 수 있다. 주소는 받은 그대로 연결한다. 공고상 예외의 문구 차이는 [신청 안내](https://edu.bccard.ai/static/contest/apply.html)와 약관 제4조 원문을 함께 본다.
- 순 사용자당 10원, 전체 리워드 1,000만원 한도, 참가작별 상한 없음. 확정 지급액 1,000원 미만은 미지급. 1~3위는 200·100·50만원. 별도 심사 없이 확정 순 사용자 순위, 동점은 먼저 등록한 참가자가 우선이다. 유효 참가작이 부족하면 해당 순위 미지급. (약관 제4~6조)
- 5만원 초과 지급은 원천징수 안내가 있으며, 정산을 위한 계좌·신원 정보는 주최자 요청 단계에서 처리한다. 팀은 대표자 계좌로 지급하고 분배는 팀이 정한다. (신청 안내·약관 제8조)
- 참가작 권리는 참가자에게 귀속되며 주최자는 공모전 홍보·결과 발표 목적의 명칭·화면·개요 사용권을 갖는다. 개발자 성명 등을 활용하는 선택적 홍보 동의는 거부해도 참가·심사에 불이익이 없다고 기재한다. 기존 타 공모전 수상작·상당한 유사성, 제3자 권리 침해 등은 제재 대상일 수 있다. (신청서 제1·2항, 약관 제9조)

## 기술과 데이터

- 대회 화면은 서비스에서 k-skill의 잇플 스킬을 호출하도록 안내한다. 신청 안내는 검색으로 받은 가맹점별 상세 URL을 변형 없이 연결하라고 한다. 잇플 홈으로의 임의 이동만으로 적격한지는 명시되지 않았다.
- API 정의서의 제휴용 가맹점 검색은 POST, 상호·지역·업종 중 하나 이상으로 검색한다. 지역은 주소 문자열 부분 일치이지 반경이 아니다. 최대 100건, 페이징 없음. GET 키워드 검색은 현재 앱 내부용이고 제휴 시 개방 가능하다고 적혀 있다. k-skill에 기술된 GET 프록시와 직접 제휴 API의 계약·권한은 동일하다고 단정하지 않는다.
- 검색 결과는 최근 1개월 결제 데이터에 기반한 매출 순이며 매출 백분위는 낮을수록 상위다. API의 최초·최종 결제 시각은 공식 영업시간이 아니다. 상세 페이지에는 결제 발생 기준 실시간 영업 현황이 표시될 수 있다. 붐비는 요일·시간대는 현재 대기 인원이나 실시간 혼잡도를 의미한다고 볼 근거가 없다. 좌표는 TM128이다. 메뉴·가격·리뷰·실시간 대기 데이터는 확인 없이 만들어내지 않는다.
- 공식 제휴 API 문서는 무료·제휴 조건 협의, 기관코드와 사전 IP 등록을 설명한다. 신청 안내는 개인 개발자의 스킬 이용을 안내하지만 k-skill 지침에는 별도 운영 제휴 전제가 있어 적용 관계가 불명확하다. 운영 전 해당 경로에 대한 권한·조건을 확인한다.
- 약관 제9조의2: 제공 데이터는 등록한 서비스에 표시하는 용도로만 사용하며 원본의 별도 축적·제3자 제공·재판매를 금지한다. 종료 후 이용도 주최자 조건에 따른다. 캐시의 허용 범위는 명시적으로 확인되지 않았다.

## 팀 판단에 필요한 미확인

1. 자체 생성형 AI가 없는 서비스의 참가 가능 여부: 문서는 ‘AI 서비스’라고 설명하지만 자체 모델 구현을 명시한 조항을 발견하지 못했다.
2. 대회 참가자에 대한 k-skill 프록시 권한·직접 제휴 의무의 적용 범위 및 호출·저장 조건.
3. 참가 폼 내부 필드, 정확한 마감 시각, 참여 요건의 정량 기준, 실제 등록 도메인에서의 측정 결과.
4. 팀 실제 구성·주제·개발 여건. 포트폴리오 우선이라는 팀 방향은 사용자 제공 정보이며 공고 요건이 아니다.

## 재사용 시 주의

화면·약관은 변경 가능하다. 최신 공고와 약관에서 확인한 내용, 사용자 진술, 우리 추론을 구별한다. 이 문서의 캡처는 확인 시점의 증거이며 신청이나 접근 권한의 승인을 뜻하지 않는다. 문의 발송·신청·배포 등은 사용자의 별도 지시에 따른다.
