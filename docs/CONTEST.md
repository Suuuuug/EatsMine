### 해야 할 일 순서

1. **동작하는 서비스를 등록 도메인에 띄운다.** "아이디어만으로는 등록 불가, 제출 도메인으로 서비스를 확인한 뒤 등록 완료." 최소 조건은 k-skill 잇플 스킬(`bccard-eatpl-search`)로 맛집을 조회하고, 응답의 상세 주소로 사용자가 브라우저에서 이동하는 흐름.
2. **상세 주소는 받은 그대로 연결한다.** 형식 `https://web.paybooc.ai/mer/web/profile/<맛집별 고유값>`. 변형·추적 파라미터·단축 URL·중간 페이지 금지.
3. **신청서·동의서 PDF를 내려받아 작성하고 대표자가 자필 서명한다.** [PDF](https://edu.bccard.ai/static/contest/eatpl_challenge_application_form.pdf). 서명은 사용자가 직접 한다. 서명본·개인정보는 저장소에 두지 않는다.
4. **스캔본을 [신청 폼](https://forms.gle/8kaCREhSgrUZTMbd8)에 업로드한다(Google 계정 필요).** 대안: `bcaimerchant@bccard.com`에 제목 `[잇플 챌린지 신청]`, 본문에 신청(대표)자명·참가자명·이메일·서비스 도메인·서비스 설명. 제출·발송은 사용자가 직접 한다.
5. **등록 완료 회신을 받는다.** 순 사용자 집계는 **등록 완료일부터** 시작한다. 늦을수록 집계 기간이 줄어든다.
6. 등록 후 대시보드에서 매일 오후 2시 갱신되는 순 사용자와 예상 지급액을 확인한다(실시간 아님).

- 상세 주소에 추적 파라미터를 붙이거나 단축 URL·중간 페이지로 감싼 경우
- **인앱 브라우저나 리다이렉트를 거쳐 유입 경로가 유실된 경우**
- 일정 시간 이상 머무르는 등 참여 요건을 못 채운 방문(기준 수치 미공개)
- 등록 호스트명과 실제 유입 경로가 다른 경우

### 보상과 규칙

- 누적 순 사용자 1명당 10원(세전), 재원 1,000만원. 1·2·3위 추가 상금 200·100·50만원(세전). 리워드는 수상 여부와 무관.
- 건당 5만원 초과 시 소득세 20%·주민세 2% 원천징수(200만원 → 실지급 156만원). 확정액 1,000원 미만 미지급. 5만원 초과 시 주민등록번호·생년월일·주소 제출 필요.
- 1인 1서비스. 같은 성명·이메일로 중복 신청 불가. 최대 4인 팀(신청서 PDF 제3조).
- 도메인은 12-03 전 1회 변경 가능, 변경 전후 유입 합산.
- 기존 서비스에 연동 추가 가능. 광고 있는 서비스 가능하나 잇플이 광고주와 제휴한 것처럼 보이는 배치는 금지.
- 모바일 앱 가능하나 상세 주소는 브라우저에서 열려야 집계.
- API 호출 횟수 제한은 없으나 비정상 호출 시 이용 제한.
- 문의 `bcaimerchant@bccard.com`. 문의·신청 메일 발송은 사용자가 직접 한다.

## 공식 안내에서 확인한 내용
- k-skill의 잇플 맛집 검색을 서비스에서 호출하고 잇플 상세로 실제 사용자를 연결한다. 작동하는 서비스 도메인 확인 후 등록된다.
- 등록 마감 2026-12-03, 산정 종료 12-13, 측정 12-14, 지급 예정 12-28. 재원 소진 시 조기 종료 가능. 확정 수치 안내 12-21, 이의 접수 12-24까지.
- 등록 완료일부터 순 사용자를 집계한다는 신청 안내와, 대시보드의 11-01부터 기간 표기는 구분해 확인한다. 집계는 매일 오후 2시 갱신.
- 상세 URL은 받은 값 그대로, 등록 호스트에서 사용자 웹 브라우저를 거쳐 이동해야 한다. 단축·중간 페이지·추적 파라미터 변경 및 인앱 브라우저 등으로 유입이 누락될 수 있다. 체류 등 추가 조건은 수치 미공개.
- 순 사용자 1명당 10원, 재원 1,000만원. 1~3위 상금 각 200·100·50만원. 확정 지급액 1,000원 미만 미지급. 세금 등은 공식 안내 참조.
- 신청서 및 동의서를 작성·서명해 폼에 제출하고 회신을 받아야 한다. 1인 1서비스, 등록 도메인은 마감 전 1회 변경 가능.

## 확인 필요
- 팀 실제 구성 및 자격, 신청서 최신 조항·제출물, 정확한 마감 시각, 심사·순위 기준, AI 필수 요건, 상세 측정/체류 조건.
- **접근 권한 주의:** 대회 신청 안내는 개인 개발자도 k-skill을 통한 사용이 가능하다고 설명하지만, k-skill 원본은 개인적 조회 제한과 운영 전 제휴·기관코드·IP 등록 등을 적는다. 문서의 적용 범위·우선관계와 상용 서비스 허용 여부를 주최 측에 확인한다. 미확인 상태에서 무단 연동·대량 수집하지 않는다.
- 신청·서명·계좌·주민등록번호 등 개인정보는 저장소에 두지 않는다. 연락은 사용자가 지시할 때만 한다.

## 2026-11-13 화면 및 신청서·약관 재검토

[대회 화면](../research/contest-evidence/2026-11-13-contest.png), [신청 안내 화면](../research/contest-evidence/2026-11-13-apply.png), [API 정의서 화면](../research/contest-evidence/2026-11-13-api.png), [잇플 화면](../research/contest-evidence/2026-11-13-eatpl-home.png), [스킬 화면](../research/contest-evidence/2026-11-13-k-skill.png) 및 [스킬 세부 지침](../research/contest-evidence/2026-11-13-k-skill-instruction.png)을 브라우저에서 직접 열어 캡처했다. [공식 미작성 신청서·약관 PDF](../research/contest-evidence/application-blank-2026-11-13.pdf)의 4쪽도 읽고 각 페이지를 이미지로 보관했다. 개인 정보나 서명이 들어간 문서는 아니다. 화면·문서는 변경될 수 있으므로 신청 전 원문을 다시 확인한다.

- **자격:** PDF 제3조는 대한민국 국민 개인 또는 최대 4인 팀이며, 한 사람이 복수 참가작에 중복 신청할 수 없다고 한다. 팀 실제 자격은 미확인.
- **연결:** [대회 화면](https://edu.bccard.ai/contest)은 참가 서비스가 잇플 스킬을 호출한다고 명시하고, [신청 안내](https://edu.bccard.ai/static/contest/apply.html)는 맛집 검색 결과로 받은 각 가맹점의 상세 주소를 그대로 연결하도록 설명한다. 단순히 아무 잇플 페이지로만 보내도 참가 요건을 충족한다는 근거는 없다. GET 프록시와 직접 제휴 API는 구분한다.
- **순 사용자:** PDF 제2·4조는 산정 기간 전체 중복 제거, 등록 도메인 경유, 분석 도구의 참여 요건을 규정한다. 체류 또는 페이지 이동 등 요건이 있으며 정확한 기준치는 공지되지 않았다. 클릭할 때마다 1명이 늘어나는 방식이 아니고 수치도 매일 오후 2시 갱신된다. 테스트 확인 전 등록 도메인에서의 집계 성공도 미확인이다.
- **순위와 권리:** PDF 제6조는 별도 심사 없이 순 사용자 순위로 수상자를 정하고 동점은 먼저 등록한 참가자를 상위로 한다. 제9조에 참가작 권리는 참가자에게 귀속한다고 기재되어 있다. 참가작 명칭·화면·개요의 주최 측 홍보 및 결과 발표 이용과 선택적 홍보 동의의 범위는 원문을 확인한다.
- **데이터:** PDF 제9조의2는 데이터를 등록한 서비스의 표시 용도로만 사용하고 원본을 별도 축적하거나 제3자 제공·재판매하지 않도록 한다. 종료 후 이용도 주최자 조건에 따른다. 직접 API 정의서는 제휴 협의·기관코드·IP 등록을 설명하고, GET 키워드 검색은 앱 내부용이며 파트너 개방 가능이라고 표시한다. 스킬의 GET 프록시가 대회 참가자에게 어떻게 적용되는지는 별도 확인이 필요하다.
- **AI:** 대회 화면은 ‘스킬을 연결한 에이전트·앱’, 신청 안내는 ‘개발자가 만든 AI 서비스’ 및 추천·검색·AI 에이전트를 예시로 든다. 확인한 신청서·약관에서 자체 생성형 AI 모델 구현을 명시적으로 요구하는 조항은 찾지 못했다. 따라서 AI 자체 구현이 의무라고 단정하지 않되, 완전히 비AI인 서비스의 참가 가능 여부는 확정하지 않는다.
- **신청 폼:** 공식 폼 링크를 브라우저에서 열었지만 Google 로그인 화면으로 연결되어 내부 필드나 제출 가능 여부는 보지 못했다. 로그인·작성·제출은 하지 않았다.

공고에서 신청 안내·서류·API·스킬·폼으로 이동하는 링크를 2026-11-13 직접 클릭해 확인한 전체 범위와 약관별 근거는 [공식 자료 종합 검토](CONTEST-REVIEW-2026-11-13.md)에 정리했다. 폼 내부는 로그인 장벽으로 미확인이다.
