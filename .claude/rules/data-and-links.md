# 데이터와 링크
대회 API의 범위·권한과 약관을 확인하고 데이터의 출처와 한계를 분명히 한다. 영업 예상 시간은 실제 영업시간이 아니고 매출 순위는 매출액이나 만족도가 아니다. 주소 문자열 검색을 거리 기반 검색으로 표현하지 않는다. 잇플 상세 주소는 API 반환값을 그대로 브라우저에서 열고 중간 경유·추적 파라미터를 넣지 않는다. 작업 문서·로그·Git·에러 응답에는 개인정보와 인증 비밀을 저장하거나 출력하지 않는다. 서비스 DB에는 고지된 목적의 최소 항목만 저장하고 접근(RLS)·보존·삭제 정책을 적용한다. 잇플 응답은 약관 확인 전까지 영속 저장하지 않는다.
