# Codex 공모전 아이디어 검토

Codex가 직접 웹 조사·발상·비판적 검토를 수행한다. Claude CLI, 외부 파이프라인이나 다른 모델의 실행을 전제하지 않는다. 사용자의 문제·선호·팀 상황과 기존 프로젝트 문서를 먼저 확인한다. 인원·기간이 미정이면 가정임을 표시한다.

- 공식 공고와 데이터 계약·이용 권한을 확인하고 출처·날짜를 기록한다. 실제 API 제공 내용과 별도 데이터가 필요한 기능을 구분한다.
- 요청에 맞게 국내외 최근 서비스·선행 사례를 웹에서 찾아 핵심 작동 방식을 확인한다. 출시 시점, 트래픽·성장 지표의 지역과 기간, 추정치 여부를 구분하며 인기와 기능 성공의 인과를 단정하지 않는다.
- 사용자 발상을 발전시키고 서로 다른 행동 원리를 결합한 후보를 직접 만든다. 각 후보에 사용자 상황, 실행 흐름, 데이터 연결, 단순 시제품 범위와 매력적인 이유를 구체적으로 적는다.
- 후보별로 유사 제품·논문 등을 조사하고 차이, 데이터 공백, 실패 가능성, 비용·권리, 반례를 검토한다. 유사 사례가 검색되지 않았다고 최초·독창적이라고 단정하지 않는다. 검증하지 못한 부분은 미확인으로 둔다.
- 요청한 독자·문체·길이에 맞춰 결과를 제공한다. 비교 판단과 우선 실험을 제시하되 근거 없는 점수와 실험 결과를 만들지 않는다. 공식 응답·사용자 데이터·링크의 취급은 관련 프로젝트 지침을 따른다.
- 다른 도구나 모델의 결과처럼 표시하지 않는다. 독립 연구·사용자 검증을 하지 않았다면 명시한다.
