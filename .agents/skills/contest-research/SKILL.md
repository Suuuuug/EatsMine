# 공모전 조사

공식 요강·신청 안내에서 기한, 자격, 제출물, 필수 데이터, 권리, 평가와 운영 조건을 출처·확인일과 함께 기록한다. 미확인은 가정과 구별한다. 후보는 해결할 사용자 문제, 데이터 접근, 데모 범위와 근거를 적고 선행 제품·논문·오픈소스 및 반례를 검토한다. 특허나 독창성을 단정하지 않는다. 아이디어 도출은 사용자가 선택한 방식과 스킬을 따른다. Codex 직접 검토는 codex-contest-ideas를, 사용자가 요청한 경우 Claude 파이프라인은 contest-idea-forge를 이용하며 결과와 출처·실현 가능성을 독립적으로 재검토한다. 실제 참가·연락·공개는 사용자 지시에 따른다.
