# 토스식 UX 라이팅 (EatsMine)

모양은 `docs/DESIGN.md`가 정한다. 이 스킬은 **문구와 흐름**만 정한다. 둘이 부딪히면 DESIGN.md §1 금지 목록이 이긴다.

## 1. 말투

| 규칙 | 이렇게 | 이렇게 쓰지 않는다 |
| --- | --- | --- |
| 해요체로 통일한다 | "지역을 칠했어요" | "등록되었습니다", "완료됨" |
| 능동형이 기본. 상태 설명에만 수동 | "기록을 지웠어요" | "기록이 삭제되었어요" |
| 긍정형. 안 되는 일은 하면 되는 일로 | "로그인하면 다른 기기에서도 보여요" | "로그인하지 않으면 볼 수 없어요" |
| 과한 높임 금지 | "지울까요?" | "삭제하시겠습니까?" |
| 명사를 쌓지 않는다 | "방문한 지역을 칠해요" | "방문 지역 기록 관리 안내" |
| 사용자 언어 | "공개 범위", "내 지도" | "visibility", "territory", "RLS" |
| 잡초 뽑기(기능 없는 단어 제거) | "17곳 중 4곳" | "현재까지 총 17개 지역 중에서 4개 지역을" |
| 한 문장에 하나만 | | 한 문장에 두 가지 안내 |

- 부정형은 정책·기술 한계로 정말 안 될 때만, 이유를 같이 쓴다.
- 오류는 사과하지 않고 할 일을 쓴다: "연결이 끊겼어요. 다시 불러와 주세요."
- 한자어 명사 대신 동사로 푼다("완료" → "끝났어요", "삭제" → "지우기").
- 강요하거나 겁주지 않는다. 선택지는 중립으로.

## 2. 버튼

- 누르면 일어날 일을 동사로: "지역 칠하기", "링크 복사하기", "기록 지우기". 결과는 같은 동사로 받는다("링크를 복사했어요").
- CTA가 하나면 `~하기`. 다음 화면으로 가면 "확인"/"다음".
- 닫는 버튼은 "취소"가 아니라 "닫기". 둘 중 하나는 "다음에".
- 버튼 끝 "→" 금지. 버튼 위에 장점을 반복하는 문구 금지.
- 잇플 이동 버튼은 "잇플에서 상세 보기"로 통일(기획서 §4 P0-04).

## 3. 설정 행 (공개 범위를 예로)

```
내 지도 공개                         [스위치]
켜면 공유 링크로 들어온 사람이 지도를 볼 수 있어요
```

- 라벨은 사용자 말 두세 단어. 컨트롤은 오른쪽. 카드로 감싸지 않는다. 한 줄에 결정 하나.
- 도움말은 **헷갈리는 행 하나에만** 한 줄. 이미 보이는 것을 설명하지 않는다("켜면 켜져요" 금지).
- 즉시 반영. 저장 버튼, 확인 대화상자, 토스트 없음. 보이지 않는 결과만 "저장했어요" 한 줄.
- 기본값이 있다. 공개 범위는 모두 꺼짐(나만 보기)이 기본(기획서 §8).
- 켜고 끄기 둘이면 스위치, 셋 이상 하나 고르기면 나란히 놓은 버튼. 선택 상태는 색만으로 구분하지 않는다(`aria-checked`/`aria-pressed`).

## 4. 빈 화면·숫자

- 빈 화면: 무엇이 생기는지 + 첫 행동 하나. "아직 칠한 지역이 없어요" + [지역 칠하기]. 설명 단락 금지.
- 숫자에는 기준을 붙인다: "17곳 중 4곳", "이번 달 제철 6개 중 2개". 숫자만 크게 띄우지 않는다.
- 예시 데이터는 예시라고 한 번 밝힌다: "예시로 채운 화면이에요". 사용자 기록처럼 쓰지 않는다.

## 5. 잇플·데이터 문구

- 출처 `eat.pl 잇플 · BC카드 결제 데이터 기반`, 순위 `전국 매출 상위 0.04%`, 시간 `영업 예상 시간`은 정해진 표현이다. 다듬지 않는다(eatpl-integration).
- 방문 기록은 사용자가 직접 남긴 것이다. "방문 인증", "결제 확인" 같은 말을 쓰지 않는다.

## 6. 점검표 (쓰고 나서 훑는다)

1. 해요체인가. "~합니다", "~됨"이 섞이지 않았는가.
2. 능동형인가. 안 되는 일을 하면 되는 일로 바꿨는가.
3. 지워도 뜻이 같은 단어(현재, 총, 다음과 같이, 매우)가 있는가.
4. 버튼이 동사이고 "취소"가 아니라 "닫기"인가.
5. 오류 문구에 할 일이 있고 사과가 없는가.
6. 코드명, 영어 약어, 개발자 용어가 보이는가.
7. DESIGN.md §1(회색 부연, 상태 칩, eyebrow, ALL-CAPS, "A · B · C", "→")을 어기지 않았는가.
