마이페이지에 '알림 설정' 섹션 React 컴포넌트(apps/web, Tailwind) 만들어줘. 섹션 제목 아래 회색으로 설명 한 줄씩 넣고, 각 항목 오른쪽에 ON/OFF 상태 배지 달고, 중요한 항목은 카드 왼쪽에 초록색 굵은 띠로 강조해줘. 항목은 '새 후기 알림', '제철음식 알림', '친구 공유 알림'.
